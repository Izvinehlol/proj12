# Exercício 2 - Média dos Valores

## 📌 Descrição
O programa lê 8 números reais, calcula a média dos valores e exibe apenas os números que estão acima da média.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um navegador.

## 💡 Lógica utilizada
- Vetores
- Estrutura de repetição `for`
- Soma e cálculo de média
- Estrutura condicional `if`

## ✅ Resultado esperado
Exibir:
- A média dos valores
- Os números acima da média
