# Exercício 4 - Interseção de Vetores

## 📌 Descrição
O programa lê dois vetores com 5 números inteiros cada e cria um terceiro vetor contendo apenas os elementos presentes em ambos, sem repetição.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um navegador.

## 💡 Lógica utilizada
- Vetores
- Estruturas de repetição `for`
- Comparação entre elementos
- Verificação de repetição
- Interseção de vetores

## ✅ Resultado esperado
Exibir os números que aparecem nos dois vetores sem repetir valores.
