# Exercício 1 - Nomes em Ordem Inversa

## 📌 Descrição
O programa lê 7 nomes de pessoas e armazena em um vetor.  
Ao final, exibe todos os nomes na ordem inversa da digitada.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um navegador.

## 💡 Lógica utilizada
- Vetores
- Estrutura de repetição `for`
- Armazenamento de dados em array
- Exibição em ordem inversa

## ✅ Resultado esperado
Mostrar os 7 nomes digitados em ordem inversa.
