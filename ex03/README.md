# Exercício 3 - Menores de Idade

## 📌 Descrição
O programa lê o nome e a idade de 9 pessoas e armazena os dados em dois vetores relacionados.  
Ao final, exibe apenas as pessoas menores de idade.

## 🛠️ Tecnologias
- JavaScript
- Visual Studio Code

## ▶️ Execução
Executar o arquivo em um navegador.

## 💡 Lógica utilizada
- Vetores relacionados
- Estrutura de repetição `for`
- Estrutura condicional `if`

## ✅ Resultado esperado
Mostrar:
- Nome
- Idade
das pessoas menores de 18 anos.
